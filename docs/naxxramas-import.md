# 纳克萨玛斯卡库导入

本批随 v0.7.9 发布；卡库已导入，新卡效果尚未实现。

## 历史范围

按用户选择截止到2014年8月、纳克萨玛斯全部区域开放时。旧牌基线继续使用原有冻结经典旧世，纳克萨玛斯新增30张卡独立存储。旧牌公开平衡改动为鹰角弓改成仅在友方奥秘揭示时增加耐久；不应用2014年9月火车王和饥饿的秃鹫削弱。

官方依据：[纳克萨玛斯上线补丁](https://hearthstone.blizzard.com/en-gb/news/14907058)、[9月削弱补丁（本次排除）](https://hearthstone.blizzard.com/en-gb/news/15982642)。此处处理可组牌数据与对应卡牌规则，未加入冒险首领、冒险关卡或游戏客户端层面的历史缺陷。

## 数据和卡池

- `classic-2014`：382张，原JSON文件保持不变。
- `naxxramas-2014`：独立30张可组牌记录、5张召唤辅助记录。移除现代新增的亡灵种族，保留当年的野兽和恶魔种族；不加载首领或解谜变体。
- `naxxramas-balance-2014`：单独存储修订后的鹰角弓，稳定ID为 `NAX_EX1_536`，共用原效果注册键。
- 新卡池 `naxxramas-2014`：经典＋纳克萨玛斯，412张。`CardReplacements` 将旧鹰角弓替换为修订版，不能把两版当作两张不同卡一起加入。

`python scripts/import_naxxramas.py --offline` 从固定的 HearthstoneJSON 253932 快照生成数据，保留原始摘录、快照和文件校验值。该数据由现代固定快照重建历史版本，不冒充2014客户端原始导出。经典导入脚本现保留其他卡池配置，避免重新导入经典时删掉扩展入口。

## 组牌与对战边界

客户端当前只提供纳克萨玛斯时代卡池；纯经典通过 Archived 标记保留在后台，不提供界面切换。版本筛选保留经典旧世与纳克萨玛斯作为卡牌来源分类，经典分类也显示当前时代的修订版本。内部修订包通过 HiddenInBrowser 隐藏，牌库只显示一张当前鹰角弓。载入旧卡组编辑时，在内存中映射为当前时代版本并保留张数，不自动改写已保存卡组；只有用户主动保存时更新保存项。

本批未实现30张新卡效果。每张新卡明确绑定尚未注册的效果键，牌库、卡组和详情显示【暂不可用】，开局验证拒绝使用，不能静默当白板。原有经典卡和修订鹰角弓仍可用。当前竞技选牌仍使用纯经典卡池，人机固定经典卡组保持原样。

此前程序把原版鹰角弓也写成只响应友方奥秘，与冻结卡面不符。本批修正：原版响应双方奥秘，纳克萨玛斯版本只响应己方。联网快照保留具体武器ID，双方从同一包解析规则。

## 验证

仅运行本批相关范围：`naxx-library,library,hunter` 46项纯规则检查、`card-sets,deck-picker` WPF检查及 `hunter` 回环TCP检查。包括30张与职业数量、辅助牌隔离、历史种族、9月削弱排除、卡组代码跨时代映射、重复版本拒绝、未实现效果开局阻止、两版鹰角弓结算与快照身份。

WPF预览检查普通与极简下真实纳克萨玛斯牌库及不可用标记。未做真人鼠标或两台电脑局域网实测。
