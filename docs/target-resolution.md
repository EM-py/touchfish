# 目标结算约定

合法性分为两阶段：出牌/操作验证在扣费前完成；施法触发、奥秘、死亡、控制权变化之后，由实际效果重新获取当前目标，不依赖原来的数量或对象引用。结算时目标减少不撤销已合法支付的牌。

- Characters 返回当前存活角色；IsPresentTarget 验证席位和实体仍存在。免疫、潜行、可指定性等仍由原操作验证或伤害规则处理，不在随机候选入口混入定向限制。
- SelectRandomTargets 过滤失效/濒死目标、按席位与实体ID去重、无放回选择，结果最多为请求数量。空集是合法结算结果。
- 顺劈斩、多重射击、叉状闪电使用 DamageRandomMinions。一次伤害批次先锁定目标快照，再批量命中；不追选亡语产生的新随从。逐次飞弹仍每发重新选择并独立清场。
- Damage 对 null、离场、错误席位或濒死目标返回零，不引入兜底目标，也不吞异常。Buff、SetHealth 使用 LivingUnit；ApplyCardEffect 对失效的指定随从目标安全失效。
- 随机数值/卡牌选择必须使用 RandomIndex，不能用假的 MatchTarget 充当抽签。动物伙伴和闪电风暴已分离这种用法。
- 法术结算后的过载、连击计数与 SpellResolved/CardResolved 保持原流程。初始不满足出牌条件仍拒绝，不扣费、不丢牌。
- 新效果用这些入口；若需要特殊的目标保留、重定向或逐次伤害语义，应明确注册，不能自行假设目标数量恒定。

验证入口：scripts/test.ps1 -Scope target-resolution -Layer rules。
联机边界用 warrior 专项中的双方真实 TCP 验证，包含减少0/1/2个候选、结果一致与手牌隐私。
该约定解决本轮目标生命周期问题，不代表所有经典交互均已证明正确。
