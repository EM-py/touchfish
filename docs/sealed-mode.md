# 现开赛（v0.7.9）

入口位于对战模式“现开”。局域网连接后双方各从三个职业中选择一个，再开18包、每包5张，共90张。只能开出当前卡池中已实现效果的本职业与中立牌，基础牌不进入卡包。纳克萨玛斯效果尚未完成，因此本批不从卡包发放这些牌。

本地后续修复：开包、可用牌与卡组行增加“…”详情，固定窗口内显示费用、攻血或耐久及完整效果。左右列表独立保存滚动位置，本方编辑和详情展开后恢复；对手进度更新只更新提示，不重建本方卡牌控件。

每人从自己的90张中选择30张，不受构筑同名两张/单传说限制，但每个卡牌ID的张数不能超过实际开出的张数。房主校验并开始正常一费、随机先后手的对局。系列赛最多三局、先两胜结束；平局计入局数，三局后按胜场确定结果。同一系列每局间可重新选择30张，原始90张不变，不重新开包。仅本房间使用，不写入用户保存卡组、草稿或偏好。

## 官方概率依据与模拟范围

来源：[炉石传说国服商城说明](https://hs.blizzard.cn/news/hs-shop.html)，2026-10-15核对。公开数据是普通卡牌包的平均获得率与保底，不是逐卡概率；没有公开服务器内部联合抽样算法。

| 类别 | 每包平均获得率 | 最多间隔包数 |
| --- | --- | --- |
| 普通传说 | 5.4738% | 40，首次10 |
| 金色传说 | 0.6089% | 361 |
| 普通史诗 | 21.7663% | 10 |
| 金色史诗 | 1.5463% | 142 |
| 金色稀有 | 7.6123% | 29 |
| 金色普通 | 8.7132% | 25 |

每包至少稀有及以上，普通品质的普通卡平均每包3.5张。传说在同稀有度收齐前防重复，其他稀有度在每张各两份前防重复；金色与普通合并计入已拥有数量。本模式没有异画、钻石卡。

`SealedPackGenerator` 按上述长期均值校准截断几何等待时间，并执行硬保底；其余槽位以稀有/普通补足五张，普通卡长期均值也纳入校准。每种特殊类别每包最多出现一次，极端多类别同时出现时优先保留到期保底，并限制为五槽；排程预防六类保底同包到期。因此这是遵循公开指标的可复现模拟，不能称为暴雪内部算法的完整复刻。

只开本职业与中立牌、限制为当前已实现卡池、每个房间作为一份新收藏重置首次保底，都是本项目的现开规则，不是官方原始卡包构成。金色只是开包记录中的品质，不改变同名牌的游戏数值，也不添加卡图或装饰。

## 联机与验证

房主生成并保存双方完整牌池。每份私有视图只含本人的职业选项、开包、牌池与组牌内容，对手只收到开包进度、确认状态与公共比分。组牌操作验证房间、独立席位版本和开出数量；对手进度刷新不确认本方尚在途的操作。牌池和开包不进入公开对局快照。协议升级为4，双方需要使用相同客户端。

纯规则专项覆盖开包数量、职业与效果限制、快照隔离、非法牌与过期请求、同名数量、局间重组、比分去重和系列结束。40000包固定种子样本得到普通传说2218张、普通史诗8688张、普通普通卡140015张，分别约5.545%、21.72%与每包3.5004张；该统计不代表每次18包会接近这些比例，首次10包保底也会改变短批次分布。

WPF与回环TCP专项覆盖连接、私人开包与组牌、首局换牌、真实出牌结算、局间更换卡牌和第二胜结束。普通548×474、极简392×300保持固定办公外观。未进行两台电脑局域网或真人鼠标实测。
